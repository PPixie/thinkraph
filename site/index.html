开始前，你可能想知道。

Thinkraph 和普通聊天界面有什么区别？+

普通对话主要按消息顺序展开。Thinkraph 以知识点为基本单位，用有向无环图表达学习依赖，并把每个节点的对话、笔记、资料和理解状态放在一起。连线表示前置知识，帮助组织学习顺序。

Agent 会直接修改我的图谱吗？+

图谱生成、分支扩展、AI 汇总和测验均先展示待采纳草稿。你核对并采纳后，经过校验才写入图谱。知识汇总会替换选中节点，保留汇总正文与来源标题，并支持一次撤销。

需要模型才能使用吗？知识会发往哪里？+

不需要模型也能手工编辑图谱、整理笔记、查看学习路径和做摘录汇总。使用 Agent 时，需要连接兼容的模型端点；请求所包含的节点内容、前置摘要、笔记、资料与对话会发送到该端点。本地保存不等于远程模型调用也离线。

这个网站可以直接运行完整工作台吗？+

这里是静态产品介绍，首页图谱使用固定示例内容演示选择节点、笔记和自测，不调用模型，也不保存到本地学习空间。完整工作台需要按上方说明在本机启动前端与 Fastify 服务；当前版本不含云端账户、协同编辑、网页抓取或文件解析。
