# 原型验证记录

2026-09-14，本机 Chrome，桌面 1680×1050 与手机 390×844。

## 功能验证

- 初始图：7 个知识节点、7 条依赖、4 个已掌握示例状态。
- 新建图谱：输入「摄影构图」与实践目标，完成后持久化 3 个模板节点、2 条依赖。
- 多图谱：新建后列表从 1 张增至 2 张，切回示例图谱时原有 7 个节点和 1 条笔记仍保留。
- JSON 导入：导入包含 2 个节点、1 条依赖的 JSON 后列表从 2 张增至 3 张，并自动切换到导入图谱；刷新后列表与当前图谱仍保留。
- Agent 扩展：2 个草稿节点和 2 条虚线依赖可见，草稿未进入持久化数据。
- 采纳：节点由 7 增至 9；撤销后恢复 7 个节点。
- 笔记：保存后由 1 条增至 2 条，刷新后仍为 2 条。
- 自测：选择正确选项后显示解释，可由用户标记已掌握；撤销后恢复学习中。
- 回答失败：原问题保留，显示重新尝试入口；重试后返回预设演示回答。
- 浅色与深色：检查主画布、右栏、输入和操作按钮。
- 手机：默认局部图谱可平移，节点学习使用浮层，输入区保持可见。
