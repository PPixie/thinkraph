# Thinkraph：图式 Agent 学习工作台

本文保留原型阶段的产品设计与后续方向。当前已实现本地 JSON 文件应用、图谱和学习空间导入导出，以及可配置模型调用；实际功能、启动方式和边界以 README.md 与 implementation.md 为准。

## 产品方向

帮助自主学习者把「想学一个领域」变成可探索、可验证、可持续生长的知识体系。主要使用场景是成人自学新领域，桌面端负责组织和深入学习，移动端负责查看、提问与复习。

产品的基本单位是知识节点。每个节点同时保存概念、问题、笔记、资料、问答历史和理解状态。知识依赖形成 DAG，学习对话围绕节点展开。知识结构可以复用和重组，聊天消息不自动变成图节点。

**示例学习目标：理解大模型应用的核心原理，独立搭建一个知识库问答助手。** 原型内的时长、掌握状态和学习记录均为演示数据，时长是示例估算。

## 用户学习闭环

1. **明确目标。** 输入领域、已有基础、希望完成的任务和每天可投入时间。允许只输入领域，也允许从空白图开始。
2. **建立骨架。** Agent 提出少量核心概念与依赖，解释各节点与目标的关系。建议首批 6-12 个节点，避免一次生成不可读的大图。
3. **围绕节点学习。** 点击概念，右侧查看简要定义、前置知识、节点对话和原始资料。可举例、追问、补基础或展开分支。
4. **沉淀理解。** 保存回答片段，补充自己的解释，或将独立问题提炼成节点。摘录需要保留对应消息和资料来源。
5. **验证与调整。** 完成小测、解释题或实践任务。掌握状态由证据辅助、用户确认；只读过答案不自动等于掌握。
6. **继续学习。** 根据前置知识、学习目标和可用时间建议下一步，允许用户跨过推荐路径自由探索。

## 页面结构

| 区域 | 内容 | 交互目的 |
| --- | --- | --- |
| 左侧导航 | 个人空间、知识搜索、图谱、路径、笔记、资料、学习进度 | 快速回到学习空间及不同组织方式 |
| 顶部 | 当前图谱、本地保存状态、导出 | 明确当前工作对象与保存位置 |
| 画布上方 | 可收起的学习主题与目标、Agent 扩展、视图与筛选 | 默认呈现目标，需要更多画布空间时压缩为单行标题 |
| 中央画布 | 知识节点、带方向的依赖、选中状态、缩略图 | 表现前置关系、多父节点与分支汇合 |
| 右侧助手 | 当前节点、学习状态、自测、对话/笔记/资料 | 让学习内容跟随选中的概念 |
| 画布工具栏 | 选择、平移、添加、连线、缩放、适应、撤销 | 提供直接、可逆的图编辑操作 |

「我的图谱」在左侧导航中展示当前浏览器保存的图谱列表。点击条目切换当前图谱；新建和导入 JSON 都追加独立图谱，不覆盖历史记录。导入文件沿用 JSON 导出结构，缺失的节点展示字段会使用安全默认值，非法或成环依赖会被过滤。

正式项目方案要求同时支持「导入知识图谱」「导出知识图谱」「导入学习空间」「导出学习空间」。单图 JSON 包保存完整节点及学习内容，导入默认追加独立图谱；空间 JSON 包保存全部未删除图谱、列表顺序、空间名称、当前图谱和界面偏好。空间导入先预览，默认合并追加，也可明确选择整体恢复；恢复前保留本地回退快照。空间导入导出尚未在当前原型实现，文件协议与一致性规则以 [本地 JSON 架构方案](architecture.md) 第 9 节为准。

桌面端三栏布局，左侧约 220px、右侧约 374px，中间自适应。两侧均可收起。标题区也可独立收起，收起后保留图谱名称、展开入口和 Agent 主操作，折叠偏好保存在当前浏览器。小于 1024px 时导航改为抽屉；小于 768px 时先显示画布，点击节点打开单一焦点的学习浮层。

## DAG 与知识模型

### 节点

建议包含：`id`、`graphId`、标题、别名、一句话定义、学习目标、类型、理解状态、预计学习时长、笔记、资料引用、对话线程、创建来源、版本号。

节点类型先保持简单：概念、方法、实践、问题。类型用图标和文字表达，掌握状态用文字和状态图标表达，不让用户只靠颜色判断。原型中「基础」「核心方法」等标签是演示分组。

理解状态：未开始 → 学习中 → 已掌握；产品版增加「待复习」。记录 `evidenceType`，区分自评、客观题、解释题和项目实践。修改关键前置知识后，下游节点提示重新检查，不直接取消用户掌握状态。

### 连线

**DAG 主层只放学习依赖。** 方向为「前置知识 → 后续知识」，允许一个节点有多个父节点，也允许不同路径共享同一节点。

- 同一目标的多个前置边，MVP 采用全部需要满足的 AND 语义。
- 生成与人工创建连线都要检查：自连、重复、节点是否存在、是否形成环。
- 新增 `A → B` 前，检查是否已有 `B → … → A` 的路径。若存在，保留原图并说明冲突路径。
- 用户可以直接学习尚未满足前置条件的节点；系统给出补基础入口，不强制锁住知识。
- 并列关联、类比、反例可以形成循环，应放在独立的「相关知识」层，默认隐藏，不参与学习顺序计算。生产版可以提供将冲突依赖改成普通关联的动作。
- 目录包含关系单独保存为分组结构，不混入学习依赖。后续若需要择一前置知识，引入明确的 OR 分组，避免把多入边含义改得模糊。

### 防止图越学越乱

新节点先做标题、别名和语义去重。命中已有概念时推荐连接到原节点，保留一个知识实体及其笔记。生成操作默认只展开一层，并限制建议数量。

少量节点使用完整卡片；中等规模按章节折叠；大图优先提供局部邻域、搜索、当前路径与缩略图。折叠只隐藏视图，不删除底层依赖。自动布局仅改变位置，用户可撤销。

## Agent 行为与控制权

### 节点问答

上下文组成建议为：学习目标与水平 + 当前节点定义 + 当前节点笔记 + 选定资料片段 + 前置节点摘要 + 当前节点对话历史。默认不带入其他分支的完整对话。

输入框上方显示可检查的上下文范围。切换节点后，对话历史跟随节点切换。生成中的请求绑定起始节点 ID，切换节点不会把回复写入新节点。支持停止、重试，问题与已生成内容保留。

常用意图：解释概念、给具体例子、找前置知识、比较概念、生成练习、扩展分支、总结为笔记。优先提供 2-3 个与当前状态有关的动作，不展开一个很长的 Agent 命令菜单。

### 扩展图谱

操作顺序：选择节点 → Agent 给出建议及理由 → 画布出现虚线草稿 → 用户逐个勾选 → 采纳 → 保存为正式节点和连线。

建议对象包含 `baseGraphVersion`、新增/复用节点、连线类型、生成理由、来源、可能冲突。服务端在正式写入前再次校验 DAG 与版本。若用户在生成期间修改了相关节点，只更新不冲突部分或提示重新生成，不能覆盖新的手工内容。

原型演示一次扩展两个后续知识点；产品版再加入补前置、合并重复节点和按目标缩小学习范围。所有生成操作应可取消，所有已采纳修改应可撤销。

### 资料与可信度

回答中的事实性主张应关联可打开的来源片段，保留文档版本或获取时间。未找到可靠来源时明确标记资料不足，不生成看似真实的链接。原型仅给 RAG 和向量相关示例附上核对过的研究/官方文档。

区分「参考资料」与「已验证结论」。有引用不代表完全正确，资料冲突时应呈现争议与不同前提。用户笔记保留自己的表述，Agent 建议更新时提供差异预览。

## 关键功能验收

| 功能 | 触发与反馈 | 完成标准 |
| --- | --- | --- |
| 创建图谱 | 输入领域，显示生成占位，生成可编辑骨架 | 空输入就地提示；可从空白开始；不会冒充完成了真实领域研究 |
| 查看节点 | 点击图节点或搜索结果 | 详情、问答、笔记和资料一致切换 |
| 直接提问 | 输入问题，Enter 发送，Shift+Enter 换行 | 显示加载、停止、错误和重试；中文输入法 Enter 不误发 |
| 扩展分支 | 点击 Agent 扩展 | 草稿虚线可见；未采纳不写入正式图；取消后不留残余 |
| 保存笔记 | 保存回答或手动编辑 | 保存到当前节点；重复摘录提示；刷新后仍存在 |
| 依赖编辑 | 拖动连接点，或选择两个知识点 | 拒绝自连、重复和成环；多父节点被保留 |
| 学习顺序 | 打开路径视图 | 所有前置节点排在后续节点之前；推荐尚未掌握且基础已满足的节点 |
| 理解自测 | 选择答案，查看解析 | 错误有解释；通过后用户可自评确认，不自动宣称全面掌握 |
| 撤销/恢复 | 工具栏或快捷键 | 节点、边、笔记、状态保持一致恢复 |
| 多图谱管理 | 查看「我的图谱」列表并点击切换；新建或导入 JSON | 当前图谱高亮；新图谱追加保存；切换后节点、笔记、对话互不串写 |
| 导出与保存 | 导出 Markdown / JSON，支持再次导入 JSON | 文件含标题、节点与对应内容；保存失败时提示导出备份 |
| 单图导入导出（正式项目） | 导出完整图谱 JSON，导入前预览和校验 | 内容及引用完整往返；同名或同 ID 图谱默认作为副本追加 |
| 学习空间导入导出（正式项目） | 空间菜单导出 JSON，导入时选择合并或整体恢复 | 列表、全部有效图谱及空间设置可恢复；整包校验失败不改变当前空间，整体恢复可回退 |

## 多节点知识汇总

在画布空白处拖动圈选，或按住 ⌘ / Ctrl 点击增减选择。选中至少两个正式节点后显示汇总工具条，展示选中数量与连接目标。框选与当前学习节点分别维护，圈选不会反复切换右侧学习内容；Esc 或「取消多选」清空选择。

「汇总为节点」打开可编辑预览，按学习路径的拓扑顺序整理节点说明、去重后的节点笔记和选中节点之间的直接依赖。当前使用本地内容提取，不调用模型，不推断不存在的知识关系。

生成时用汇总节点替换所有选中节点。新节点初始为未开始，继承拓扑顺序最早的选中节点的位置和全部父节点；同级节点按图谱稳定顺序确定。所有选中节点指向外部子节点的连线改由汇总节点发出，相同子节点仅保留一条汇总连线；选区内部连线移除，其他节点之间的依赖保留。其他选中节点的父节点不额外并入汇总节点的父节点。生成后重新验证 DAG，不产生自连、悬空引用或循环。

汇总正文与来源节点 ID、标题一起保存，正文同时存入新节点笔记。原节点及其独立笔记、对话随替换移除，原笔记内容已纳入可编辑汇总草稿；被删除节点上未完成的演示回复停止生成。来源名称作为静态记录显示。预览展示删除数量、继承的父节点和重连的外部子节点数量。

生成是一次可撤销操作，支持恢复、本地持久化和 JSON / Markdown 导出；刷新、切换图谱不保留临时多选状态。草稿节点不参与汇总。

## 节点类别

节点类别保存在 `data.kind`，是创建节点时写入的展示标签，不参与 DAG 校验、学习排序或状态计算。示例节点和学习模板按内容角色预设类别，例如「基础」「方法」「概念」「核心方法」「应用」「实践」；汇总节点为「知识汇总」，Agent 分支草稿为「延伸知识」。自建节点在添加表单中选择「基础」「方法」「概念」「核心方法」「应用」「实践」或「自建知识」，默认选择「自建知识」。导入图谱沿用文件中的类别，缺省数据使用通用「知识点」标签。

## 空态、异常与边界

- **空图谱：** 解释节点用途，提供添加第一个节点的唯一主动作。
- **无笔记/资料/对话：** 各有与当前节点有关的起点，不复用泛化「暂无数据」。
- **生成中：** 保持原图稳定，加载区域与结果形状接近；允许取消。
- **回答失败：** 错误显示在对话位置，保留问题，重试不复制用户消息。
- **本地保存失败：** 明确说明，提供可用导出；不能继续显示已保存。
- **删除节点：** 显示影响与确认，保留其他节点，支持撤销。
- **重复与成环：** 先校验再变更；依赖冲突不以静默反向来修复。
- **生成版本过期：** 重新校验相关节点及依赖，按修改差异确认。
- **大图性能：** 分级展示、视口内渲染、布局放入 Worker、生成分批应用。

## 视觉与可访问性

视觉语言为专注的知识工作台。浅灰绿色画布、白色内容面、单一低饱和绿色强调。绿色用于当前学习焦点和有效动作，空白用于分隔层级。图节点有细边框和轻阴影，使可拖动物件区别于背景。

`DESIGN_VARIANCE: 4`：稳定结构中保留自然分支布局。`MOTION_INTENSITY: 2`：只做按钮反馈和即时状态变化。`VISUAL_DENSITY: 7`：缩短顶部、导航和详情区的垂直节奏，节点仍只显示识别所需信息，详细解释进入右栏。页面标题使用 24px，详情标题使用 19-21px，节点标题使用 16px，正文使用 11-12px，形成紧凑但清晰的字号层级。

Geist 自托管字体搭配系统中文无衬线字体。圆角规则为控件 6px、节点 10px、对话框 16px。使用 Radix Themes 的对话框、按钮、选择器和勾选控件；图编辑使用 React Flow。浅色与深色共用语义令牌。焦点可见；状态含文字；Tab 可到达交互元素；右栏标签页支持左右方向键。

触控端采用图谱/节点内容分开操作的模式，保留列表式学习路径作为替代视图。后续产品化需继续增加连线的完整中文键盘编辑、读屏描述与触控目标尺寸审计。

## MVP 与后续范围

**首版闭环：** 单用户多图谱、按目标建图、DAG 编辑、节点问答、分支草稿与采纳、节点笔记与来源、学习状态、简单自测、下一步推荐、本地 JSON 持久化、单张知识图谱及完整学习空间的导入导出。

**后续增强：** PDF/网页导入并定位来源片段、语义去重、基于学习证据的复习、子图折叠、多节点比较、生成版本差异、知识关联层。

**暂缓：** 多人实时协作、多人 Agent 编排、复杂自动评分、跨用户知识社区。先验证图谱是否帮助用户形成自己的解释和找到下一步。

建议观察的指标：创建后完成首次节点学习的比例、保存自己笔记的比例、分支建议采纳/撤回情况、自测后的错误修正率、间隔后仍能解释关键概念的比例。不把生成节点数或聊天轮数当成学习成效。

## 原型实现边界

此交付为 React 可交互原型，未连接真实模型、检索后端、账户或云存储。预设问答明确标注为演示；新图谱使用三个通用模板节点，基础与每日时间保存在本地但未做真实个性化排课。图谱列表、当前图谱、节点笔记和对话保存在浏览器，新建或导入会追加一张独立图谱；生产版仍需服务端同步、权限和冲突处理。

图拖动/平移/缩放、节点选择、搜索、节点对话、笔记、分支勾选与采纳、依赖校验、拓扑排序、示例自测、主题切换、撤销、导出均可体验。关联层、来源上传、服务端版本校验、自动语义去重与真实评估属于设计规格，未在本原型中实现。
